# AI Contributions

AI-assisted contributions are welcome.

By submitting AI-assisted code, contributors confirm that they have personally reviewed and verified the changes, understand how the code works, and take full responsibility for the produced code. Contributors are responsible for ensuring that their changes are correct, secure, maintainable, appropriately licensed, and consistent with this project.

Before opening a pull request, run the relevant checks and describe any AI assistance that materially affected the implementation. Do not submit generated code without understanding and testing it.
